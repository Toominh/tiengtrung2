THƯ MỤC FILE ÂM THANH - BẢNG PHIÊN ÂM TIẾNG TRUNG
====================================================

Đặt các file MP3 vào thư mục này theo định dạng:
  <âm tiết>.mp3
  Ví dụ: ba.mp3, po.mp3, mei.mp3, nü.mp3

Danh sách tất cả âm tiết cần file MP3:
ba, bo, bi, bu, bai, bei, bao
pa, po, pi, pu, pai, pei, pao, pou
ma, mo, me, mi, mu, mai, mei, mao, mou
fa, fo, fu, fei, fou
da, de, di, du, dai, dei, dao, dou
ta, te, ti, tu, tai, tao, tou
na, ne, ni, nu, nü, nai, nei, nao, nou
la, le, li, lu, lü, lai, lei, lao, lou
ga, ge, gu, gai, gei, gao, gou
ka, ke, ku, kai, kei, kao, kou
ha, he, hu, hai, hei, hao, hou

Nếu không có file MP3, trang web sẽ tự động dùng Web Speech API
để phát âm tiếng Trung qua giọng nói tổng hợp của trình duyệt.
